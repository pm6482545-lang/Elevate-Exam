# Elevate Kenya Exam Engine

An automated, KICD curriculum-aligned national exam generation platform designed to build precise, scenario-based Kenyan national exams with strict adherence to official testing blueprints, cognitive weighting, and dual-column LaTeX/PDF outputs.

## Features
- **Strict Curriculum Boundaries:** Pulls sub-strands and weighting rules based on grade, subject, and term.
- **Authentic Formatting:** Generates two-column layouts with vertical dividing lines and 2x2 matrix multiple-choice options.
- **Dual Export:** Export straight to clean PDFs or copy Overleaf-ready LaTeX code.
